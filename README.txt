#HOSTEL MANAGEMENT SYSTEM

TECH STACK:
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL

HOW LOGIN WORKS:
- User enters ID + Password
- Backend checks database
- If role = student -> student dashboard
- If role = manager -> manager dashboard

FEATURES:
- Dynamic login
- Database connection
- Role based authentication
- Student data from database
- Manager can see all students
- Students can only see own information

RUN BACKEND:
1. cd backend
2. npm install
3. node server.js

OPEN FRONTEND:
frontend/index.html
